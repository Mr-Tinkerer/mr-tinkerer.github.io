## Overview

This glossary defines terms used in the Hermes Agent documentation.

---

## Custom Endpoint

A configuration option in Hermes that allows users to connect to local or remote Large Language Model (LLM) services. Custom endpoints enable integration with various AI models without requiring cloud connectivity.

## LLM (Large Language Model)

An artificial intelligence model capable of understanding and generating human-like text. LLMs can be used for text generation, code writing, analysis, and various natural language processing tasks.

## Qwen3.5

A specific version of the Qwen language model series. Different variants exist with varying context sizes and parameter counts (e.g., Qwen3.5-9B uses approximately 9 billion parameters).

## Context Size

The maximum number of tokens (words or subword units) that an LLM can process in a single request. Larger context sizes allow the model to understand longer documents or maintain better conversation history, but require more RAM.
