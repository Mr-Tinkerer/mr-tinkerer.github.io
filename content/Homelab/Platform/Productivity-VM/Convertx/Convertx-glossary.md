## ConvertX

A self-hosted web UI for converting files between formats (documents, images, audio, video, and more) via a single drag-and-drop interface, backed by a collection of open-source conversion engines under the hood so I don't have to install and remember a different CLI tool for every format pair. I run it on the Productivity VM as the general-purpose "convert this file to that format" tool, alongside [[Homelab/Platform/Productivity-VM/Stirling-pdf/Stirling-pdf-installation|Stirling PDF]] which covers PDF-specific manipulation instead. See [ConvertX (GitHub)](https://github.com/C4illin/ConvertX).
