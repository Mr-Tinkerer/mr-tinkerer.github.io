## Overview

This page documents terms used across the ConvertX bucket.

## ConvertX

A self-hosted web UI for converting files between formats (documents, images, audio, video, and more) via a single drag-and-drop interface. It uses a collection of open-source conversion engines under the hood to avoid installing and remembering a different CLI tool for every format pair.

It runs on the Productivity VM as the general-purpose "convert this file to that format" tool, alongside Stirling PDF which covers PDF-specific manipulation instead.

See [ConvertX (GitHub)](https://github.com/C4illin/ConvertX).
