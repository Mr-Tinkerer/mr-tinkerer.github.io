## Overview

This page documents terms used across the Stirling-PDF bucket.

## Stirling PDF

A self-hostable, all-in-one web tool for viewing, merging, splitting, compressing, converting, and manipulating PDF files. Stirling PDF packages dozens of individual PDF operations (that would otherwise require separate CLI tools or paid online services) behind one web UI.

It runs on the Productivity VM as the dedicated PDF workhorse, distinct from ConvertX which handles general file-format conversion — Stirling PDF is used whenever a task is specifically about PDF manipulation (merging scanned pages, compressing large files before sharing, stripping metadata, etc.).

See [Stirling PDF (official site)](https://www.stirlingpdf.com/).
