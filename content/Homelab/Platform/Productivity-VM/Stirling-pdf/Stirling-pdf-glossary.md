## Stirling PDF

A self-hostable, all-in-one web tool for viewing, merging, splitting, compressing, converting, and otherwise manipulating PDF files, packaging dozens of individual PDF operations (that would otherwise mean separate CLI tools or paid online services) behind one web UI. I run it on the Productivity VM as the dedicated PDF workhorse, distinct from [[Homelab/Platform/Productivity-VM/Convertx/Convertx-installation|ConvertX]] which handles general file-format conversion — Stirling PDF is what I reach for whenever a task is specifically about a PDF (merging scanned pages, compressing a large file before sharing it, stripping metadata, etc.). See [Stirling PDF (official site)](https://www.stirlingpdf.com/).
