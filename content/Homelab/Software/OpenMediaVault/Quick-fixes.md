## Overview

This page documents essential post-installation configuration tasks for OpenMediaVault.

## Configuration Steps

### Timezone

Set the timezone under `System → Date & Time`.

### Admin Password

Change the admin password from the installer default under `Account → Password`.

### System Updates

Apply system updates under `System → Update Management → Updates`.
