## GitHub Actions (as a Pages source)

A build-and-deploy source option for [[#GitHub Pages|GitHub Pages]] where a workflow file in `.github/workflows/` builds the site and publishes it, instead of GitHub serving whatever's already committed to a branch. I used this option for this wiki (see [[Github-pages-repository-setup|Repository Setup]]) instead of the [[Old-blog-site/GitHub-Pages/Github-pages-glossary#Git worktree|worktree-based branch deploy]] I used for the old blog.
